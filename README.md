# 🔐 Password Strength Checker

A simple web application that checks the strength of a password based on length and character rules.

## 🚀 Features
- Checks password strength (Weak / Medium / Strong)
- User-friendly web interface
- Built using Python and Flask

## 🛠️ Tech Stack
- Python
- Flask
- HTML/CSS

## ▶️ Run Locally
```bash
pip install flask
python app.py
